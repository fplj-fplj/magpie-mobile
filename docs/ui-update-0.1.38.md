# 0.1.38 界面更新与验收

本轮承接 DeepSeek Harness 会话 `session-533805ab-b5e8-47fe-8c29-77be748a6a16` 和 P9 真机反馈方案。上一轮因设备桥授权失败停在诊断阶段；本轮实现网络、电池设置、中文字体和二级导航，并优化聊天阅读。完整插件执行链仍待开发。

设计采用编辑叙事方向：暖纸色页面、反相运行状态面板、文楷标题与正文、清晰的无衬线导航。管理页保持工具所需的信息密度。将技能的 Card、Empty State、导航和 Chat 模式映射到现有原生 Compose 组件，CSS Token 对应 `UiTheme.kt` 与 `UiSpacing.kt`。

| 入口 | 内容 |
| --- | --- |
| 网关首页 | 运行状态、启停、本机端点、模型数、四个管理入口、网络与电池摘要 |
| 接入应用 | 核心连接、重连、Base URL / Key / cURL 复制 |
| 客户端密钥 | 密钥列表、签发、模型与额度限制 |
| 用量与速度 | 近期请求、聚合用量、额度、模型速度 |
| 路由与号池 | 模型别名、降级、密钥轮询 |
| 更多 → 模型目录 | 网关模型与 models.dev 目录 |
| 更多 → 插件与工具 | 插件文件、候选示例、MCP 配置 |
| 更多 → 系统与诊断 | 网络、电源、运行输出、版本、许可、备份入口进度 |

页面名称和二级位置通过 `rememberSaveable` 恢复；每个目的地有独立滚动状态。凭据、草稿与诊断输出继续只保留在现有内存状态中。切换页面、返回和旋转不触发模型推理，服务仍只由用户启停。

## 验证边界

本地仅做源文件与资产检查，不运行 Gradle、Go 或 APK 编译。GitHub Actions 执行既有 JVM 回归、Go 安全测试、集成烟测与固定签名 APK 构建；新增字体文件哈希、实际 cmap 汉字字形及 OFL 检查，以及电池设置回退和网络类型测试。

真机验收仍需安装 Actions 生成的 APK：

1. 检查版本为 `0.1.38-paper-ui`。网关未运行时不显示虚构模型数量；启动后状态与端点保持一致。
2. 从四个首页入口进入，分别用顶部返回和系统返回回到首页；旋转后保持所在二级页和滚动位置。切换底部导航不重复发送聊天。
3. 检查「网关」「对话」「霞鹜文楷」等标题和正文有文楷字形，按钮保持无衬线。检查浅色、深色和系统主题。
4. 在 320dp 宽度和较大系统字号下检查主题选择与接入复制按钮换行，长模型名不遮挡操作。
5. 在系统页设置电池优化；确认显示实际打开目标，返回后刷新状态。ROM 拒绝某个目标时回退其他页面；全部不可用时出现手动路径。
6. 切换 Wi-Fi、蜂窝和断网；网络摘要应实时变化，不把权限缺失当作断网。
7. 查看聊天历史、切换会话、读取更早消息，检查成功、失败和中断状态。停留在列表底部时跟随新消息；阅读较早消息时不强行跳转。

字体真机字形、ROM 设置页面行为、实际布局和运行稳定性需要以上设备检查，静态检查不能代替。
